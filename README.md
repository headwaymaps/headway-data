This contains two course grained tilesets used by Headway and visible on maps.earth.

1. A low resolution raster terrain for when you are zoomed out. This account for the texture mountains when you are zoomed way out.
2. A low resolution vector land coverage tileset. This accounts for the color of the plains, deserts, forests, ice, etc. when zoomed way out.

The assets were generated by hand (IIRC using tippecanoe, from natural earth and overture datasets).

They probably should be generated dynamically from source data like the rest of Headway, but they don't change frequently, so I haven't prioritized that process.
